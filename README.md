# Proyecto IA

Portfolio de aprendizaje y proyectos de Inteligencia Artificial aplicada.
## Proyecto

Asistente de IA para apoyar la toma de decisiones en operaciones industriales.

### Objetivo

Detectar tendencias y situaciones anómalas antes de que se produzca una alarma crítica, utilizando datos históricos y conocimiento operativo.

### Funciones iniciales

- Analizar datos de operación.
- Detectar tendencias anómalas.
- Identificar patrones previos a eventos.
- Mostrar posibles causas.
- Proponer comprobaciones al operador.
- Consultar procedimientos y antecedentes.
- Mostrar las fuentes utilizadas.
